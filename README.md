# 삼육대학교 메타버스

브라우저에서 돌아다니는 3D 캠퍼스 메타버스. 파일 하나(`sahmyook.html`)로 동작하고, three.js는 CDN에서 불러온다.

- **배포 주소의 첫 화면(`/`)** = `sahmyook.html` (캠퍼스, 온라인 멀티플레이)
- **`/cafe.html`** = `index.html` (초대형 무인카페, 혼자 하는 버전)

배포 때 `vercel.json`의 빌드 명령이 두 파일을 `dist/`에 위 이름으로 복사한다. 로컬에서는 파일을 더블클릭해서 열면 된다.

## 온라인 (Firebase Realtime Database)

닉네임을 입력하고 들어오면 같은 주소로 접속한 사람들이 서로 보이고 채팅할 수 있다. 로그인은 없다.

- 접속자 위치·자세는 `rooms/syu-campus/players/{id}`, 채팅은 `rooms/syu-campus/chat`에 저장된다. 창을 닫으면 접속자 기록은 서버가 지운다(onDisconnect). 2분 넘게 소식이 없는 기록은 다른 접속자가 지운다.
- **의견 게시판**(정문 앞 게시판·오른쪽 위 📝)은 `rooms/syu-feedback/chat`을 쓴다. 채팅과 같은 규칙(작성만, 120자)이라 규칙을 따로 바꿀 필요가 없다. 맨 위에 "추가·업데이트했으면 하는 것을 남겨 달라"는 공지가 고정돼 있다.
- 같은 건물·같은 층·같은 방에 있는 사람만 화면에 보인다. 자전거·감정표현도 다른 사람에게 보인다.
- 데이터베이스에 연결하지 못하면 "혼자 모드"로 계속 동작한다.

## 놀거리 · 화면

- 처음 들어오면 30초 안내가 한 번 뜬다(❓로 다시 보기).
- 🚲 공유 자전거(정문 정류장·학생회관·중앙도서관), 🐈 캠퍼스 고양이 5마리, 🦆 제명호 오리 먹이, 🪙 분수 동전·운세, 🥤 자판기, 📸 포토존 4곳과 P 키 사진(저장 가능), 😀 감정표현(1~5), 🌙 낮/밤(N, 저녁 7시~아침 6시는 밤으로 시작).
- 하늘 환경맵(유리창·호수에 하늘이 비침), 창턱·인방·커튼월 멀리언, 건물·나무 밑 그늘, 플레이어 주변 풀포기, 밤에 켜지는 창문·가로등.

### 데이터베이스 준비 (한 번만)

1. Firebase 콘솔 → 프로젝트 `metaverse-658b1` → **빌드 › Realtime Database › 데이터베이스 만들기** (위치는 아무거나. 코드가 미국·싱가포르·벨기에 주소를 차례로 찾는다)
2. **규칙** 탭에 `database.rules.json` 내용을 붙여 넣고 **게시**

규칙은 `rooms/*/players`와 `rooms/*/chat`만 읽고 쓰게 열어 두고, 이름 16자·채팅 120자 제한과 채팅 수정·삭제 금지를 검사한다.
